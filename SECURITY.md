# Security Policy

## Supported Versions

PulseTask is currently in alpha. Security fixes are applied to the latest `main` branch and latest tagged release.

## Reporting a Vulnerability

Please do not report vulnerabilities in public issues.

Send a private report with:

- Summary of the issue
- Reproduction steps
- Potential impact
- Suggested fix (optional)

Use the contact path described in SUPPORT.md.

## Response Targets

- Initial acknowledgment: within 3 business days
- Triage outcome: within 7 business days
- Remediation target: depends on severity and complexity
