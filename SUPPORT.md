# Support

## Getting Help

Use GitHub Discussions for questions and usage help.

Use GitHub Issues for reproducible bugs and concrete feature requests.

## Before Opening a Bug

- Confirm you are on a recent commit or release
- Check existing issues for duplicates
- Include logs, environment details, and reproduction steps

## Maintainer Contact

Until a dedicated security/contact channel is created, use repository maintainers via GitHub private contact options for sensitive topics.
