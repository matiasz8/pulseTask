# UI Guidelines (Modern, Award-inspired, Native)

PulseTask aims for a premium modern interface while remaining native to GNOME and accessible.

## Principles

- Clarity under pressure: countdown is visually dominant.
- Progressive disclosure: show only what is needed for the current action.
- One primary action per state.
- Keyboard-first interaction paths.
- High contrast and readable typography at all times.

## Visual System

- Define semantic colors for urgency levels: safe, warning, critical, expired.
- Keep spacing and typography on consistent scales.
- Use subtle motion for transitions; reserve strong motion for deadline events.

## Inspiration Approach

Use award-winning products as interaction references, not as visual templates to copy.

- Fast Company Innovation by Design (recent UX winners)
- Awwwards Apps and Sites of the Day

## Pull Request Requirements for UI Changes

- Include before/after screenshots.
- Explain rationale (hierarchy, interaction cost, accessibility).
- Confirm no keyboard navigation regressions.
